Agilent 87XX Series Instrument Driver Readme

To rate this driver, go to the driver download page on the Instrument Driver Network.

1. Overview

Instrument Driver Technology: LabVIEW Plug and Play (project-style)
Manufacturer: Agilent Technologies
Supported Language(s): LabVIEW
Supported Model(s): 8753B/C/D;8719B/C/D/ES/ET*, 8720B/C/D/ES/ET*, 8722B/C/D/ES/ET*, 8753ES/ET*
* Note: This instrument driver was originally developed for the 8753B/C/D. There is additional functionality offered by the ES/ET models that is not implemented by the instrument driver. The 8719B/C/D, 8720B/C/D, and 8722B/C/D may only support a subset of functionality implemented in the instrument driver.
Model(s) Tested: HP8753D
Interface(s): GPIB
Firmware Revision Tested: Not Available

Certified: Yes
NI Supported: Yes
Source Code Available: Yes

Driver Revision: 2.0
Original Release Date: 01/01/94
Current Revision Date: 07/18/05

2. Required Software

Some software components need to be installed before using this instrument driver. The minimum versions of these components are listed below, and can be downloaded from the Download Site.

VISA 5.0 or later

For more details, refer to the LabVIEW Help under Help » VI, Function, & How-To Help.

3. Known Issues

To report issues or provide feedback about this instrument driver, please contact technical support.
Three VIs, Output to Plotter.vi, Read Error Queue.vi and Status Reporting.vi were originally developed using several functions from the NI-488.2 library. You will need this package if you wish to use these VIs.

-This instrument driver was originally developed for the 8753B/C/D. There is additional functionality offered by the ES/ET models that is not implemented by the instrument driver. The 8719B/C/D, 8720B/C/D, and 8722B/C/D may only support a subset of functionality implemented in the instrument driver.
