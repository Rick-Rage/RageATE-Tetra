SPATIAL_CYCLES		 216
; The SPATIAL_CYCLES register declares the number of chirps in a
; vertical scanline. It used to be UBER important for triggering
; other state machines (antennaController.v, adcController.v,
; rampController.v, pulseModController.v, etc.) which ran in
; the ISU FPGA and performed "per chirp" repeating activity.
; But now in the wideband Payette product these other activities
; have moved into the FPGAs located on the AMs and the RFSM
; and hence SPATIAL_CYCLES is only now used by the non-critical
; trigger_generator.v state machine.

; Note that during most chirps 2 Demod circuits will be simultaneously
; active (possibly on different AM cards) but during a few only 1
; Demod circuit will be active. Hence determination of the correct
; value for the SPATIAL_CYCLES register requires deep inspection
; of the AmCombinedTables...txt file due to the fact that operations on
; the different AMs overlap.

; In the "JK1" design AM1 by itself is active for the first 21 chirps.
; During the first 3 of these chirps only AM1's Demod1 is active and then
; for the next 18 chirps two Demod circuits on AM1 are active. 
; Then AM1 and AM2 are both active for 6 chirps. During these 6 chirps
; both AM1 and AM2 have only 1 Demod channel active. During the first
; 3 of these 6 chirps AM1 provides the Tx antenna used by both AM1 and
; AM2 and during the last 3 of these 6 chirps AM2 provides the Tx antenna
; used by both AM1 and AM2. Then only AM2 is active by itself for 18 chirps.
; During these 18 chirps AM2 always has 2 Demod circuits active. Then both
; AM2 and AM3 are active for 6 chirps, etc.

; Hence the total number of chirps is 3 + 18 + ( 8 * 6 ) + ( 7 * 18 ) + 18 + 3 = 216
; Note that 216 is half of 432 not half of 426 (which is the # of logical antennas) !!

SPATIAL_PERIOD		 2059
; Since state_clk is 150 MHz the SPATIAL_PERIOD (a.k.a. SP)
; value of 2059 results in a freq chirp period of 13.727 usec.
; Note that 13.727 usec/chirp * 216 chirps = the correct 2.9 msec
; scanline time.
