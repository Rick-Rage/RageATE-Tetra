; This file describes the registers in the T.I. DS90UB925Q Serializer.
; These registers (and their subfields) are described in Section 7.6 of the datasheet.

; The contents of this file are parsed by my cTreeViewBox class.
; A semi-colon indicates a comment line.
; The format of the non-indendented lines is:
; RegName  RegAddr  RW/RO DefValue
; The format of the indendented lines is:
; LSBit   NumBits  Unsigned/Signed  FieldName  PopUpToolTip(optional)
; where blanks (space characters) separate these 5 fields.
; The PopUpToolTip includes the remainder of the line and hence can include blanks.
; The PopUpToolTip can be made multiline by including the 2 char sequence "\n".
; LSBit counts from 0.
; Values can be expressed in hex if preceded by 0x or 0X.

I2cDeviceId              0  RO  8 0x18
  1  7  Unsigned  DeviceID     7-bit address of serializer
  0  1  Unsigned  ID_Setting   if 1 DeviceID is from reg, if 0 from IDx pin
; This reg is actually writable but I mark it read-only so that the I2C device ID
; set by the IDX pin is not disturbed.

Reset                    1  RW  8 0x00
  7  1  Unsigned  RemoteAutoPowerDown  power down when no bidi control channel link is detected
  2  5  Unsigned  Reserved             these bits are reserved
  1  1  Unsigned  DigitalReset1        resets the entire digital block including the registers
  0  1  Unsigned  DigitalReset0        resets the entire digital block except for the registers

Configuration0           3  RW  8 0xDA
  7  1  Unsigned  BackChannelCrcChecker  enable back channel CRC check
  6  1  Unsigned  Reserved               this bit is reserved
  5  1  Unsigned  I2cRemoteWriteAutoAcknowledge  automatically acknowledge I2C remote write
  4  1  Unsigned  FilterEnable           enable filter that rejects HS, VS, or DE pulses narrower than 2 PCLKs
  3  1  Unsigned  I2cPassThruMode        enable I2C pass-through mode
  2  1  Unsigned  Reserved               this bit is reserved
  1  1  Unsigned  PCLK_Auto              auto switch over to the internal osc. in the absence of PCLK
  0  1  Unsigned  PixelClockEdgeSelect   parallel interface is strobed on the rising clock edge
; The 925 chip's power-up default for this reg is 0xD2 but we want to enable I2C pass-through mode
; (or else we won't be able to communicate with the remote 926 deserializer located on the RFSM).

Configuration1           4  RW  8 0x80
  7  1  Unsigned  InputFailSafeState           if 1 failsafe to low, if 0 failsafe to high
  6  1  Unsigned  Reserved                     this bit is reserved
  5  1  Unsigned  CrcErrorReset                clear back channel CRC error counter
  4  1  Unsigned  RGB_DE_Gate                  gate RGB Data with DE
  3  1  Unsigned  BackwardCompatibilitySelect  if 1 backward compatibility mode is set by register, if 0 by MODE_SEL pin
  2  1  Unsigned  BackwardCompatibilityMode    be backward compatible with DS90UR906Q
  1  1  Unsigned  LfModeSelect                 if 1 frequency range is set by register, if 0 by LFMODE (accomplished with MODE_SEL pin)
  0  1  Unsigned  LfMode                       if 1 PCLK range 5-15 MHz, if 0 15-85 MHz
; The 925 chip's power-up default for this reg is 0x80.
; Change this to 0x83 (or else use the MODE_SEL pin) if you want LFMODE (meaning PCLK is between 5-15 MHz).

; The LFMode must be selected when PCLK < 15 MHz. LFMode can be
; selected either via the Configuration1 register or via the
; MODE_SEL pin.  The advantage of using MODE_SEL is that
; "When LFMODE is changed a PDB reset is required".

I2cControl1              5  RW  8 0x00
  5  3  Unsigned  Reserved             these bits are reserved
  3  2  Unsigned  SDA_OutputDelay      if 00 240 nsec, if 01 280 nsec, if 10 320 nsec, if 11 360 nsec
  2  1  Unsigned  LocalWriteDisable    disable remote writes to local device registers
  1  1  Unsigned  I2cBusTimerSpeed     if 1 I2C bus watchdog timer expires after 50 ms, if 0 after 1 sec
  0  1  Unsigned  I2cBusTimerEDisable  disable the I2C bus watchdog timer that attempts to clear a hung bus

RemoteDeviceID           6  RO  8 0x58
  1  7  Unsigned  DeserializerDeviceID   I2C address of the remote deserializer
  0  1  Unsigned  DesDeviceIdFrozen      prevents autoloading of I2C address of remote deserializer
; This reg is actually writable but I mark it read-only so that the deserializer I2C address received
; by the 925 serializer through the communication link is not disturbed.
; The 925 chip's power-up default for this reg is 0x00. However this register
; gets loaded automatically based upon the 2-way communication between the 925 serializer
; and the 926 deserializer.

; The 925 datasheet uses the name "DeserializerID" for this register but the 926
; datasheet calls it the "RemoteDeviceID" which I prefer.

SlaveID                  7  RW  8 0x00
  1  7  Unsigned  SlaveDeviceID          I2C address of the remote slave device attached to the remote deserializer
  0  1  Unsigned  Reserved               this bit is reserved
; Note that if we don't initialize the SlaveID and SlaveAlias registers
; the V3ISU won't be able to communicate with the RFSM's FPGA.

SlaveAlias               8  RW  8 0x00
  1  7  Unsigned  SlaveDeviceAlias       I2C address that will be remapped to the remote slave device attached to the remote deserializer
  0  1  Unsigned  Reserved               this bit is reserved

CrcErrorsLSB            10  RO  8 0x00
  0  8  Unsigned  NumBackChannelCrcErrorsLSB   8 least sig digits of number of back channel CRC errors

CrcErrorsMSB            11  RO  8 0x00
  0  8  Unsigned  NumBackChannelCrcErrorsMSB   8 most sig digits of number of back channel CRC errors

GeneralStatus           12  RO  8 0x05
  4  4  Unsigned  Reserved               these bits are reserved
  3  1  Unsigned  BistCrcError           back channel CRC error detected during BIST
  2  1  Unsigned  PclkDetect             valid PCLK detected
  1  1  Unsigned  DesError               back channel CRC error
  0  1  Unsigned  LinkDetectStatus       if 1 cable link is detected, if 0 fault condition
; The 925 chip's power-up default for this reg is 0x00 but the LSBit (bit0) will
; assert if cable link is detected (this bit is read-only) and bit 2 will assert
; if PCLK is toggling (this bit is also read-only). Note that PCLK will not be toggling
; on the 925 located on the V3ISU which connects to the RFSM.
