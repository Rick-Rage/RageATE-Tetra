External Source Configuration:

Any measurement using an external source must first be added to the PNA manually using the front panel GUI.  
NOTE:  Any Preset or Reset will remove the external source.  The user must then add the external source again in order to use it in a measurement.


Mixer Measurement Configuration:

Prior to running the mixer measurements both EX_VMC01.mxr and EX_SMC01.mxr files must be copied to the PNA's directory structure.
