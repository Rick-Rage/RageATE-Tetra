Keysight/Agilent PSG MXG Series Instrument Driver Readme

To rate this instrument driver, go to the Agilent PSG MXG Series driver download page on the Instrument Driver Network.


1. Overview

Instrument Driver Technology: LabVIEW Plug and Play (project-style)
Manufacturer: Keysight/Agilent Technologies
Supported Language(s): LabVIEW
Supported Model(s): E8241A, E8244A, E8251A, E8254A, E8247C, E8257C, E8267C, E8257D, E8267D, N5181A, N5182A, N5183A, N5161A, N5162A, N5171B, N5172B, N5181B, N5182B, N5173B, N5183B
Model(s) Tested: N5182A, E8257D, N5172B
Interface(s): GPIB, Ethernet, USB
Firmware Revision(s) Tested: A.01.20 (N5182A), C.05.37 (E8257D), B.01.10(N5172B), B.01.57(N5172B)
Certified: Yes
NI Supported: Yes
Source Code Available: Yes
Driver Revision: 2.0
Original Release Date: 08/03/2007
Current Revision Date: 09/15/2016

3. Known Issues



To report issues or provide feedback about this instrument driver,  please contact technical support.



PSG series models were not tested thoroughly, due to unavailability of instruments for this series. For model tested N5182A, all options are valid in firmware revision A.01.20 or later.

{Notes for REV 2.0}

  • SCPI Node Express VI is only supported in LabVIEW 2012 or later.

  • Configure Frequency Channel.vi: B850BDCS option for Channel Band is unsupported.

  • Load and Save Data (Generic Data).vi: NVHDR for Destination File must follows a strict internal format or it generates error messages. Also, it must be created after the NVWFM file has been written first.

  • Configure ALC.vi: External Detector option for ALC Source is only valid when a 20/40 GHz external Millimeter-Wave accessory is connected to the signal generator.

  • Configure ARB.vi and Agilent PSG MXG Series Operate N5102A Module in Output Mode.vi: To enable ARB, make sure you fist select a waveform.

  • Perform Diagnostic Loop Back Test.vi: You must have a N5102A attached to the rear panel LVDS port.
